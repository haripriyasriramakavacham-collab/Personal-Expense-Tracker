# Personal-Expense-Tracker
A desktop GUI application to track personal income and expenses.
# Features
1. Add, edit, view, update and delete transactions.
2. Search transaction by date or category.
3. Categorize expenses: Food, Travel, Bills etc.
4. Auto calculates total spending and category distribution summaries.
5. Data stored locally with CSV file.
# Tech Stack
Language - Python
GUI - Tkinter
Storage - CSV file
# How to Run
1. Ensure Python 3.x is installed.
2. Run 'python main.py' (replace 'main.py' with your script's filename).
